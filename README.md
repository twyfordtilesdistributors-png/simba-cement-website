# Simba Cement Website

Responsive static website foundation for the Simba Cement project.

## Current build
- Responsive desktop/mobile layout
- Corporate red, white and charcoal visual system
- Sticky navigation with mobile menu
- Hero, About, Products, Solutions, Quality, Projects and Contact sections
- Placeholder contact details
- Contact form UI ready for a real submission service

## Important before launch
Company claims, product names/specifications, certifications, imagery, contact details and any statement of affiliation should be verified and replaced with approved information. This repository is a website project and should not be represented as the manufacturer's official website unless that authorization exists.

## Deployment
The site is plain HTML/CSS/JavaScript and can be deployed with GitHub Pages or another static host, then connected to a custom domain.
